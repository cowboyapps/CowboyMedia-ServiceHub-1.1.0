---
name: Ticket link prefixes
description: Customers need to see HTTP or HTTPS in support-ticket links.
---

Support-ticket link labels must display their `http://` or `https://` prefix,
not only the domain and path.

**Why:** The user said their customers need to be able to see that part.

**How to apply:** Preserve the prefix in visible link text when changing link
presentation; compact long links without removing the protocol.
